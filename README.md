# Rohan Mahajan — Portfolio

A responsive personal portfolio website built with HTML and CSS.

## Files

- `index.html` — Website structure and content.
- `style.css` — Styling, layout, and responsive design.

## Run locally

1. Download or clone this repository.
2. Keep `index.html` and `style.css` in the same folder.
3. Open `index.html` in a web browser.

No build tools or dependencies are required.

## Customize

- Update the About section with your own introduction.
- Replace the profile and project image placeholders with real images.
- Replace the sample project cards with your actual projects and their URLs.
- Update the skills list as your skills grow.

## Publish with GitHub Pages

1. Create a GitHub repository named `Rohan-Git69.github.io` for a user site,
   or use any repository and enable Pages in its Settings.
2. Upload `index.html`, `style.css`, and this README to the repository root.
3. In the repository, open **Settings → Pages**.
4. Under the build/deployment section, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)` folder, then save.
6. Wait for GitHub Pages to publish the site.

## Note about the contact form

The contact form is currently a front-end form using a `mailto:` action.
It may open the visitor's configured email application and is not a reliable
server-side message system. To receive messages directly through the website,
connect a form service or build a backend.
